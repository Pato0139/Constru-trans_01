## Notas de Actualización vs MER Anterior

| Elemento | Cambio |
|----------|--------|
| `Cliente` → `ClienteVIP` | Modelo real es ClienteVIP |
| `EPS PK` | Es `codigo_eps` (string), no entero autoincremental |
| `Vehiculo PK` | Es `id_vehiculo`, con alias `id` |
| `Proveedor PK` | Es `codigo_proveedor` |
| `MaterialConstruccion PK` | Es `cod_material`, con relación a `Catalogo` y `UnidadMedida` |
| `Stock PK` | Es `material_id` (OneToOne con Material) |
| `Pedido → Entrega` | Relación **OneToMany**, no OneToOne |
| `Pago → Factura` | Pago depende de Factura, no directamente de Pedido |
| `MetodoPago PK` | Es `codigo_metodo_pago` (string) |
